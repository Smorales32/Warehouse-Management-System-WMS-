# Warehouse Management System (WMS)

A personal WMS application inspired by real warehouse workflows and my
experience working with warehouse management systems.

## Features

- Login system
- Inventory lookup
- Receive inventory
- Inventory adjustments
- Create picking jobs
- Pick processing
- Short-pick handling
- Over-pick handling
- Job completion
- Persistent inventory data

## Tech Stack

- React Native
- Expo
- TypeScript
- LocalStorage

## Project Status

MVP / Version 1
